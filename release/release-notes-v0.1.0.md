# quiet-progress v0.1.0

First public Windows release.

## Highlights

- Floating or desktop-bottom progress widget for Windows.
- Year, month, day, and multiple custom milestone modes.
- Five melancholy themes.
- Vietnamese, English, and Japanese UI.
- Resizable widget, system tray controls, and optional Windows startup.

Download `quiet-progress-windows.zip`, extract it, and run `quiet-progress.exe`.
