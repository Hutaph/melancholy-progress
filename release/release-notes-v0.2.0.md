# quiet-progress v0.2.0

The widget now changes mood with the time of day.

## New

- Optional theme scheduler in the melancholy style menu.
- `Old Sunset` from `06:00` to before `18:00`.
- `Rainy Night` from `18:00` to before `06:00`.
- Your manually selected theme returns when the scheduler is disabled.

Download and run `quiet-progress.exe`.
